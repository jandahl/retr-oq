Background Window

This window sits behind Test Window and is INACTIVE: the framework's own .inactive-title-bar class draws a plain bar with just the centered title -- no pinstripes, no close/zoom buttons. Click anywhere in it to bring it to front and make it active instead.

Test Window

This window has a fixed size and position. Dragging it by the title bar moves the whole frame; scrolling inside it only moves the content below -- the frame itself, and the desktop around it, never move.

Scroll down inside this window to see the desktop stay put around it.
