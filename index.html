retr-oq

Retro desktop/window-manager prototypes — one per theme, each in its own subdirectory with its own vendored framework under vendor/. See README for how this relates to jandahl/oq.

  • 1984 Mac (System 1) Pinstriped title bars, draggable fixed-size windows, active/inactive chrome — built on @sakun/system.css.
  • DOS Text-mode windows that drag and resize in whole character-cell steps, not free pixels — built on BOOTSTRA.386's DOS-EGA reskin of Bootstrap.
  • Commodore 64 LOAD"$",8 disk listing, RUN loading-screen border flicker — a from-scratch stylesheet, no vendored framework (see README).
  • Windows 98 Taskbar, Start menu, real draggable-and-resizable-from-any-edge windows with minimize/maximize/close — built on 98.css.
  • Windows XP Luna Blue taskbar and Start menu, same real window chrome as Windows 98 — built on XP.css, reusing the shared Redmond window manager.
  • Mac OS 8.1 Platinum menu bar, a single close/zoom title-bar pair and one bottom-right growbox, smooth pixel dragging — built on classic.css.
  • Windows 7 Aero glass taskbar, blurred/glossy title bars, a round Start orb — built on 7.css, reusing the shared Redmond window manager.
