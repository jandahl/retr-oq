Background Window

This window sits behind Test Window and is INACTIVE: the framework's own .inactive-title-bar class draws a plain bar with just the centered title -- no pinstripes, no close/zoom buttons. Click anywhere in it to bring it to front and make it active instead.

Test Window

This window has a fixed size and position. Dragging it by the title bar moves the whole frame; scrolling inside it only moves the content below -- the frame itself, and the desktop around it, never move.

Scroll down inside this window to see the desktop stay put around it.

Notes

This window opened from a desktop icon, not a window that was already on screen -- click the "Notes" icon on the desktop (top right) any time to reopen it after closing.

retr-oq: a real fixed-size, fixed-position window on a real full-viewport desktop, with its own internal scroll, built on the real vendored framework (vendor/mac1984/system.css, from npm's @sakun/system.css) instead of hand-rolled chrome. Drag a title bar; click a window to make it active; scroll inside a window; close and reopen it. See README.md for how this relates to jandahl/oq.
