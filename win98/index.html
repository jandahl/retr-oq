About retr-oq

This is a prototype Windows 98 desktop -- a taskbar with a real Start menu, and windows you can drag by the title bar and resize from any edge or corner, minimize down to a taskbar button, and maximize to fill the screen.

No functional app lives inside a window yet -- that's deliberately left for a follow-up once the window manager itself is solid.
