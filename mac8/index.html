About This Macintosh

This is a prototype Mac OS 8.1 (Platinum) desktop -- a top menu bar instead of a taskbar, windows with a close box and a zoom box you drag by the title bar and grow from the single bottom-right growbox, same as the real Mac OS 8.1 Finder.

Built on classic.css -- see this theme's style.css for what's vendored versus this theme's own additions (menu bar, desktop icons, OQ!/DECON window bodies).
